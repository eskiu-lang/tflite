## `<tflite>`

TensorFlow Lite model inference (`<tflite>`).

tflite_load() reads a .tflite file and makes an interpreter for it; set_input()
fills an input from typed data, invoke() runs the model and output(i) is the
result. Every fallible call returns a Result whose error is a message from
TensorFlow Lite or from the checks here; the message lives in a buffer that the
next error reuses, so copy it to keep it. Models and interpreters have a release
method, meant to be paired with defer:

```eskiu
TfliteInterpreter it = tflite_load("model.tflite", null)?;
defer it.release();
int[2] shape = {1, 4};
it.set_f32(0, &x[0], &shape[0], 2)?;
it.invoke()?;
*float y = it.output(0).f32();
```

The whole C API is in `<tflite/raw>` for anything this layer does not cover.

### TfliteOptions

```eskiu
struct TfliteOptions {
    int threads;
    int delegate;
    bool fallback;
    bool precision_loss;
    string delegate_path;
}
```

Interpreter options. The zero value is TensorFlow Lite's default CPU kernels.
threads is the thread count (0 keeps TensorFlow Lite's choice). delegate is one
of TFLITE_CPU, TFLITE_XNNPACK (XNNPACK on every operation it supports, quantized
ones included, as Python's interpreter runs by default), TFLITE_GPU (Metal on
Apple, OpenCL or OpenGL on Linux), TFLITE_COREML, or TFLITE_AUTO (the GPU when its
delegate is found, else the CPU). A delegate that is missing or cannot take the
model is an error, unless fallback is set: then the interpreter runs on the CPU
and its delegate field says so. precision_loss lets the GPU compute in 16-bit
floats. delegate_path is the delegate's library, when it is not beside
libtensorflowlite_c.

### TfliteTensor

```eskiu
struct TfliteTensor {
    *TfLiteTensor handle;
    String name;
    int type;
    List<int> shape;
    List<int> signature;
    uint64 count;
    uint64 bytes;
    *void data;
    float scale;
    int zero_point;
}
```

An input or output tensor: its name, element type, shape (with signature giving
-1 for a dynamic dimension), quantization (scale 0 when it has none) and data.
The data belongs to the interpreter; it moves when an input is resized, and
output shapes can change with each run, so read them after invoke().

### TfliteInterpreter

An interpreter for a model: `delegate` is the delegate it runs on (TFLITE_CPU when none
applied or it fell back), `inputs` and `outputs` its tensors. Free it with release().


## `<tflite/image>`

Image preprocessing for vision models (`<tflite/image>`).

The functions here work on 8-bit RGBA pixels, four bytes per pixel, rows packed
with the top row first: what `<gpu/image>`'s image_load returns for PNG and JPEG
files, and what most decoders and cameras give. The buffers they return come
from alloc and go back with free.

```eskiu
*uint8 face = tflite_image_crop(img.rgba, w, h, x, y, size, size, TFLITE_BORDER_REFLECT);
*uint8 small = tflite_image_resize(face, size, size, 128, 128);
TfliteImageFormat f = tflite_format_unit();
it.set_image(0, small, 128, 128, &f)?;
```

### TFLITE_BORDER_ZERO, TFLITE_BORDER_CLAMP, TFLITE_BORDER_REFLECT

```eskiu
const int TFLITE_BORDER_ZERO = 0;
const int TFLITE_BORDER_CLAMP = 1;
const int TFLITE_BORDER_REFLECT = 2;
```

What tflite_image_crop puts outside the image.

### TfliteImageFormat

```eskiu
struct TfliteImageFormat {
    bool nchw;
    bool bgr;
    float scale = 1.0;
    float[3] mean;
    float[3] std;
}
```

How pixels become tensor values: value = (pixel * scale - mean[c]) / std[c],
with c the channel in the tensor's order (B, G, R when bgr is set) and a zero
std taken as 1. Layout NHWC ([1, h, w, 3], as TensorFlow Lite models take
images) unless nchw is set ([1, 3, h, w]). An int8 or uint8 input gets the value
quantized with its scale and zero point. The zero value with its default scale
gives 0..255 RGB in NHWC.

### tflite_format_unit

```eskiu
TfliteImageFormat tflite_format_unit()
```

Values in 0..1.

### tflite_format_signed

```eskiu
TfliteImageFormat tflite_format_signed()
```

Values in -1..1, (pixel - 127.5) / 127.5: the MobileNet and EfficientNet-Lite
convention. A quantized uint8 input with scale 1/128 and zero point 128 then
receives about the pixel values themselves.

### tflite_format_imagenet

```eskiu
TfliteImageFormat tflite_format_imagenet()
```

Values in 0..1, normalized with the ImageNet mean and standard deviation (RGB).

### tflite_format_raw

```eskiu
TfliteImageFormat tflite_format_raw()
```

Values in 0..255, as the image holds them.

### tflite_image_crop

```eskiu
*uint8 tflite_image_crop(*uint8 rgba, int w, int h, int x, int y, int cw, int ch, int border)
```

The cw x ch region whose top left corner is (x, y), which may reach outside the
image; border says what fills the outside (zero, the nearest edge pixel, or the
image reflected about its edge pixels as OpenCV's BORDER_REFLECT_101).
null when a size is not positive.

### tflite_image_resize

```eskiu
*uint8 tflite_image_resize(*uint8 rgba, int w, int h, int nw, int nh)
```

Resizes to nw x nh with bilinear filtering and half-pixel centers (as ONNX
Resize with mode linear and half_pixel, TensorFlow's tf.image.resize and
OpenCV's INTER_LINEAR). It does not
average when shrinking; for that use tflite_image_resize_area.

### tflite_image_resize_area

```eskiu
*uint8 tflite_image_resize_area(*uint8 rgba, int w, int h, int nw, int nh)
```

Resizes to nw x nh by averaging the source pixels each output pixel covers:
the better filter for shrinking. Enlarging falls back to tflite_image_resize.

### tflite_image_into

```eskiu
Result<int, string> tflite_image_into(*uint8 rgba, int w, int h, *TfliteImageFormat f, *TfliteTensor t, int index)
```

Writes the image into item index of a tensor shaped [N, h, w, 3] (or [N, 3, h, w]
with nchw) of float32, float16, int8 or uint8, for batches. The tensor is
usually an interpreter's input, it.input(i).

### TfliteInterpreter_set_image

```eskiu

```

Fills input i with the image, as item 0 of its batch. An input whose height and
width are dynamic (-1 in its signature) is resized to the image's.
